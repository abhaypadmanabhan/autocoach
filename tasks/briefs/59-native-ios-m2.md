**Deviations from spec (with rationale):**
1. **MCQ answer submitted as the letter ("A"…"D"), not the option text.** The web sends the prefixed option text (e.g. `"A) Some option"`); the backend `normalize_mcq_answer` then strips the prefix to the letter. Submitting the bare letter is format-independent and always grades correctly regardless of how the LLM formatted the option string. Noted here per the brief's deviation rule. `input_method:"click"` is sent for both MCQ and TF (web parity: `setInputMethod("click")`).
2. **System-mono font fallback** instead of bundled Space Grotesk/Inter/Space Mono TTFs — explicitly allowed by the M2 brief ("System-mono fallback OK for data text"). TTF bundling deferred.

**Backend note (no edits — flagged per handoff protocol):** The `evaluate_mcq` grader compares `normalize_mcq_answer(user)` vs `normalize_mcq_answer(correct)`, which only yields the letter if the answer string starts with `"A)"/"A."/"A "` OR is a bare single letter.
